Total order broadcast

All processes deliver messages in the same order.

▶If the message m2 depends on the message m1, meaning that m2 is

broadcast after m1 is received on the same process, then the total
order broadcast indicates that m1 is delivered before m2 on all
processes.
▶When m1 and m2 are broadcast by the same process, the delivery

could be non-causal.

Implementation of FIFO-total order broadcast

FIFO-total order broadcast can be implemented using Lamport’s scalar
time (Skeen’s algorithm):

▶The sender broadcasts the message to all processes.
▶Each recipient sends its local scalar time back to the sender and

keeps the message on hold.
▶The sender collects all the received timestamps and broadcasts the

largest one to all recipients.
▶Recipients order messages by this timestamp and deliver a message

when it is first in the queue.

Broadcast

Implementation of FIFO-total order broadcast

FIFO-total order broadcast can be implemented using Lamport’s scalar
time (Skeen’s algorithm):

▶The sender broadcasts the message to all processes.
▶Each recipient sends its local scalar time back to the sender and

keeps the message on hold.
▶The sender collects all the received timestamps and broadcasts the

largest one to all recipients.
▶Recipients order messages by this timestamp and deliver a message

when it is first in the queue.

Alternatively, any process that wants to broadcast a message should send
the message to a leader, and the leader will perform a FIFO broadcast of
the message to all processes.

▶The naive implementation of the algorithm is not fault tolerant.
▶It needs to be supplemented by a leader-election algorithm.

The simple synchronizer

▶Assumption: In each round, each process sends one and only one

message to all neighbors. If not, combine multiple messages into one
or send a dummy message.

▶Synchronizer: A process moves to the next round only after it

receives messages from all neighbors.

▶Properties:

1
In physical time, any two adjacent processes may be only one
round apart.

![pymupdf:45:8](pymupdf:45:8)

2
When process i is in round roundi, it can receive messages only
from rounds roundi or roundi + 1 from its neighbors.
