Introduction to Apache Spark

What is Apache Spark?

Apache Spark is a unified engine for large-scale data
analytics.

▶Unified: Spark supports a wide range of analytics tasks from simple

data loading and SQL queries to machine learning and streaming
computation, with a consistent set of APIs.
▶Data analytics: The scope of Spark is limited to an analytics

engine. Unlike Hadoop, Spark does not provide a storage system.
But Spark runs well on many storage systems including HDFS.
▶Large-scale: Spark is built for large and parallel computations on

clusters of as many as thousands of nodes. The algorithms are
highly scalable and efficient.

Apache spark is a multi-language engine for data engineering. It supports
Python, SQL, Scala, Java and R.

Lazy evaluation

Lazy evaluation means that Spark will wait until the very last moment to
execute computational instructions.

▶The following operations do not even read the file, but they build up

a plan for the computations.

>>> df = spark.read.csv("flights.csv", schema)
>>> dfNullRemoved = df.filter(~psf.isnull("ARRIVAL_DELAY"))
>>> dfSorted = dfNullRemoved.select(
...
"YEAR", "MONTH", "DAY", "AIRLINE", df.colRegex("`.*ARRIVAL.*`")
... ).sort(col("ARRIVAL_DELAY").desc())

▶To view the plan, use

>>> dfSorted.explain(mode = "formatted")

▶The following commands will carry out computations:

>>> dfNullRemoved.count()
>>> dfSorted.first()

Projecting DataFrames

Projecting a DataFrame refers to the act of selecting a subset of columns
from the DataFrame or creating new columns based on existing ones.
Examples include

▶Selecting/Reordering specific columns:

df.select("col2", "col1")
▶Creating new columns:

df.withColumn("newCol", col("col1") + col("col2"))
▶Renaming columns:

df.withColumnRenamed("oldName", "newName")

Spark’s implementation:

▶The new schema is generated during planning.
▶For each row in the partition, a new UnsafeRow is created by

selecting/reordering fields or evaluating expressions.
