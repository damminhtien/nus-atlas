\begin{topicblock}
\topic{01}{PART I: SQL QUERY LOGIC}
\when{Select, group or order rows. SQL syntax: MySQL 8.4; schemas are local to each pattern.}
\pattern{Query syntax sketch}
\begin{lstlisting}
SELECT [DISTINCT] expressions
FROM R [LEFT JOIN S ON join_condition]
WHERE row_condition
GROUP BY keys HAVING group_condition
ORDER BY expression DESC LIMIT n;
\end{lstlisting}
R/S are input relations; replace expressions/conditions/keys; n is a nonnegative row limit.
\key{RULE: logical order}
\sql{FROM/JOIN/ON -> WHERE -> GROUP BY -> HAVING}
\sql{-> WINDOW -> SELECT -> DISTINCT -> ORDER BY -> LIMIT}.
Window results need an outer query/CTE for filtering. SELECT aliases work in MySQL ORDER BY/HAVING, not WHERE. Group selected expressions unless aggregated or functionally dependent on grouped keys.
\trap{LIMIT applies after filtering/ordering. Window ordering details are in 08--09.}
\key{String operations}
\sql{LIKE} \texttt{'\%abc\_'}: \% any length, \_ one character; case sensitivity follows collation. \sql{CONCAT(a,b)} concatenates; \sql{||} is normally OR. \sql{SUBSTRING(s,1,3)} starts at 1; position 0 gives empty. \sql{CHAR_LENGTH} counts characters; \sql{LENGTH} bytes.
% Source: user-supplied set-operator table; MySQL 8.4 set operations (W16).
\key{Set operators / duplicates}
SQL query results are bags. Align column count and compatible types. Without ALL, each result row occurs at most once. With ALL, if a row occurs $m$ times in A and $n$ times in B: UNION gives $m+n$, INTERSECT $\min(m,n)$, EXCEPT $\max(m-n,0)$ copies.
\ex{One-column query results: $A=[1,1,2,3]$, $B=[1,2,2,4]$. Apply each operator to A then B:}
\par\begin{tabular}{@{}ll@{}}
\textbf{SQL operator} & \textbf{Result}\\
\sql{UNION} & \sql{[1,2,3,4]}\\
\sql{UNION ALL} & \sql{[1,1,1,2,2,2,3,4]}\\
\sql{INTERSECT} & \sql{[1,2]}\\
\sql{INTERSECT ALL} & \sql{[1,2]}\\
\sql{EXCEPT} & \sql{[3]}\\
\sql{EXCEPT ALL} & \sql{[1,3]}
\end{tabular}\par
\trap{Results above are shown sorted for comparison; only final ORDER BY guarantees row order.}
Symmetric difference: \sql{(A EXCEPT B) UNION (B EXCEPT A)}.
\end{topicblock}

\begin{topicblock}
\topic{02}{NULL / EMPTY AGGREGATES}
\when{Missing values, empty inputs or anti-joins.}
SQL uses three-valued logic: $\boxed{\{\mathrm{TRUE},\mathrm{FALSE},\mathrm{UNKNOWN}\}}$ (T/F/U). Ordinary scalar comparisons with NULL give U; test missing values with \sql{IS NULL}.
% Source: user-supplied NULL comparison table; MySQL comparisons/NULL (W17).
\key{NULL comparison results}
\par\begin{tabular}{@{}ll@{}}
\textbf{Expression} & \textbf{Result}\\
\sql{NULL = NULL} & UNKNOWN\\
\sql{NULL <> NULL} & UNKNOWN\\
\sql{NULL = 5} & UNKNOWN\\
\sql{NULL IS NULL} & TRUE\\
\sql{NULL <=> NULL} & TRUE\\
\sql{5 <=> NULL} & FALSE
\end{tabular}\par
MySQL \sql{a <=> b} is NULL-safe equality. \sql{COALESCE(x,0)} replaces NULL; \sql{NULLIF(x,0)} returns NULL if zero. Arithmetic propagates NULL.
\begin{center}\begin{tabular}{@{}ll|ll@{}}
$T\land U$ & $U$ & $F\land U$ & $F$\\
$T\lor U$ & $T$ & $F\lor U$ & $U$\\
$\neg U$ & $U$ & &
\end{tabular}\end{center}
\key{RULE: truth values by SQL context}
\par\begingroup\setlength{\tabcolsep}{1.6pt}
\begin{tabular}{@{}lccc@{}}
\textbf{SQL context} & \textbf{TRUE} & \textbf{FALSE} & \textbf{UNKNOWN}\\
\sql{WHERE/HAVING} & Keep row & Drop row & \textbf{Drop row}\\
\sql{CHECK} & Allow & Reject (error) & \textbf{Allow}
\end{tabular}\endgroup\par
\key{Counts and grouping}
\sql{COUNT(*)}: rows; \sql{COUNT(x)}: non-NULL x; \sql{COUNT(DISTINCT x)}: distinct non-NULL x. SUM/AVG/MIN/MAX ignore NULL. On empty input COUNT is 0; the others are NULL. No GROUP BY: one aggregate row even on empty input; grouped empty input: no groups. NULL group keys/DISTINCT values are collected together.
\pattern{Anti-join and NULL}
\sql{x NOT IN (SELECT y FROM S)} compares x with every y using three-valued logic. \sql{NOT EXISTS (SELECT 1 FROM S WHERE S.y=R.x)} asks whether any equality match exists.
\ex{For x=5: NOT IN values [1,NULL] gives U; [1,2] gives TRUE. If R.x=NULL and S=[1], NOT IN is U but correlated NOT EXISTS is TRUE.}
\cond{Use NOT EXISTS for "no matching row". With nullable outer keys it is not an automatic rewrite of NOT IN; state the desired NULL policy. Equality-based forms agree when both keys are non-NULL.}
\ex{For x = [10,NULL,20]: COUNT(*)=3, COUNT(x)=2, SUM=30, AVG=15. LEFT JOIN with no match gives one NULL-extended row: COUNT(*)=1, COUNT(S.id)=0. Count a non-NULL right key to count matches.}
\end{topicblock}

\begin{topicblock}
\topic{03}{JOINS / MULTIPLICATION}
\when{Combine relations; preserve unmatched rows; count facts per parent.}
INNER: matched pairs. LEFT: all left rows plus NULLs for missing right. RIGHT: symmetric. CROSS: every pair. MySQL has no native FULL OUTER JOIN; combine LEFT with unmatched-right rows using UNION ALL. ON matches rows before outer preservation; a right-side WHERE filter may remove unmatched rows.
\ex{R keys [1,2], S keys [2,3]: INNER [2]; LEFT [(1,NULL),(2,2)]; FULL adds (NULL,3). A key appearing twice on both sides produces 4 matched rows.}
\trap{Joining independent one-to-many facts with m and n children produces m*n rows per parent; counts/sums multiply. Pre-aggregate each fact to the target grain first.}
\pattern{Pre-aggregate independent facts}
Schema: Community(area PK), School(area,score), Crime(area); score is numeric or NULL. Each community appears once.
\begin{lstlisting}
WITH SchoolAgg AS (
 SELECT area, COUNT(*) AS schools,
        AVG(score) AS avg_score
 FROM School GROUP BY area
), CrimeAgg AS (
 SELECT area, COUNT(*) AS crimes
 FROM Crime GROUP BY area
)
SELECT c.area, COALESCE(s.schools,0) AS schools,
       s.avg_score, COALESCE(k.crimes,0) AS crimes
FROM Community c
LEFT JOIN SchoolAgg s ON s.area=c.area
LEFT JOIN CrimeAgg k ON k.area=c.area;
\end{lstlisting}
\ex{2 schools and 3 crimes: raw join has 6 rows, inflating each count to 6; independent aggregates return 2 and 3. Retain NULL average for communities without known scores.}
\end{topicblock}

\begin{topicblock}
\topic{04}{TYPES / DATES / CASTS}
\when{Choose types, convert text or select a time interval.}
\sql{INT/BIGINT}: integers; \sql{DECIMAL(p,s)} exact decimal; FLOAT/DOUBLE approximate; CHAR fixed, VARCHAR variable; TEXT/BLOB text/binary. DATE date, TIME time/duration, DATETIME date-time, TIMESTAMP session-time-zone conversion. JSON structured data. Boolean commonly TINYINT(1).
\pattern{Expression / predicate fragments}
\begin{lstlisting}
-- score: valid nonnegative integer text
MIN(CAST(score AS UNSIGNED))
WHERE dt >= '2012-02-01' AND dt < '2012-03-01'
DATE_ADD(dt,INTERVAL 1 DAY)
DATEDIFF(end_date,start_date) -- days, ignores time
TIMESTAMPDIFF(HOUR,start_dt,end_dt)
DATE_FORMAT(dt,'%Y-%m'); EXTRACT(YEAR FROM dt)
\end{lstlisting}
% Source: Project 1 Q1; date format retained as an explicit input example.
\pattern{Parse a known text format (fragments)}
\begin{lstlisting}
-- Tue Dec 16 2014 12:30:00 GMT-0800 (PST)
-- For strings of this shape, select February 2015:
WHERE SUBSTRING(selling_date,5,3)='Feb'
  AND SUBSTRING(selling_date,12,4)='2015'
-- Parse recorded local clock time; timezone not applied:
STR_TO_DATE(LEFT(selling_date,24),
            '%a %b %d %Y %H:%i:%s')
-- Sample above parses to 2014-12-16 12:30:00 (local).
\end{lstlisting}
\cond{UNSIGNED cast assumes valid nonnegative integer text. STR\_TO\_DATE's format must match the input; a mismatched/invalid value is not a valid parsed date.}
\trap{String order: \sql{'100' < '20'}; numeric order: $20<100$. For DATETIME use a half-open month interval; BETWEEN dates can omit most of the final day.}
\end{topicblock}

\begin{topicblock}
\topic{05}{SUBQUERIES / DIVISION}
\when{Scalar lookup, membership or "for every required item".}
Scalar subquery: one column, at most one row; zero rows gives NULL, multiple rows is an error. EXISTS asks whether any row exists. A correlated subquery refers to an outer row. IN tests membership; \sql{= ANY} is IN.
\key{RULE: ANY/ALL (U = UNKNOWN)}
ANY is OR, ALL is AND across comparisons. For \sql{5 > ANY/ALL (SELECT y FROM T)}, RHS lists the subquery's y values.
\par\begin{tabular}{@{}lll@{}}
\textbf{RHS values} & \textbf{ANY} & \textbf{ALL}\\
3,NULL & TRUE & U\\
8,NULL & U & FALSE\\
empty & FALSE & TRUE
\end{tabular}\par
ANY: TRUE dominates U; ALL: FALSE dominates U.
\trap{\sql{x > ALL (SELECT y FROM T)} is not generally equivalent to \sql{x > (SELECT MAX(y) FROM T)}. For [3,NULL], 5>ALL is U but 5>MAX is TRUE; for empty input ALL is TRUE, while MAX is NULL.}
\pattern{For every: double NOT EXISTS}
Schema: A(id PK), Required(bid), R(aid,bid); R.aid references A.id. Assume non-NULL IDs. Return an A row iff no required bid is missing from its R rows.
\begin{lstlisting}
SELECT a.id
FROM A a
WHERE NOT EXISTS (
 SELECT 1 FROM Required q
 WHERE NOT EXISTS (
  SELECT 1 FROM R r
  WHERE r.aid=a.id AND r.bid=q.bid
 )
);
\end{lstlisting}
\ex{A=[a1,a2], Required=[b1,b2]; R={(a1,b1),(a1,b2),(a2,b1)}: returns a1. If Required is empty, both A rows qualify (vacuous truth).}
\key{Count alternative}
\begin{lstlisting}
SELECT r.aid FROM R r
JOIN Required q ON q.bid=r.bid
GROUP BY r.aid
HAVING COUNT(DISTINCT r.bid) =
       (SELECT COUNT(*) FROM Required);
\end{lstlisting}
\cond{Count form assumes unique, non-NULL required IDs and a nonempty Required set; it omits A rows with no R rows. DISTINCT prevents duplicate R rows inflating coverage.}
\end{topicblock}

\begin{topicblock}
\topic{06}{CTE / AGGREGATE LEVELS}
\when{Compare rows to group statistics, or traverse a graph.}
CTE: named query result scoped to one statement; chain with commas. First derive each group statistic, then compare original rows to that statistic.
\pattern{Rows above their group's mean}
Student(dept,mark); mark numeric/NULL. NULL departments form one group; \sql{<=>} matches that group.
\begin{lstlisting}
WITH DeptAvg AS (
 SELECT dept, AVG(mark) AS mean_mark
 FROM Student GROUP BY dept
)
SELECT s.* FROM Student s
JOIN DeptAvg d ON s.dept <=> d.dept
WHERE s.mark > d.mean_mark;
-- Window equivalent (keeps detail rows):
WITH T AS (
 SELECT s.*, AVG(mark) OVER (PARTITION BY dept) AS m
 FROM Student s
)
SELECT * FROM T WHERE mark > m;
\end{lstlisting}
\key{Global average from subgroup averages}
$\bar{x}=\frac{\sum_i n_i\bar{x}_i}{\sum_i n_i}$, where $n_i$ counts non-NULL inputs to subgroup mean $\bar{x}_i$. Drop zero-count groups; if all counts are 0, the mean is undefined/NULL. AVG(group means) weights groups equally.
\ex{Group1=[10,20], mean15, n=2; group2=[90], mean90, n=1. Global=(2*15+1*90)/3=40; unweighted means average=52.5 (wrong for individuals).}
\key{Recursive graph closure (MySQL 8+)}
\begin{lstlisting}
WITH RECURSIVE Reach(a,b) AS (
 SELECT a,b FROM Edge
 UNION DISTINCT
 SELECT r.a,e.b FROM Reach r
 JOIN Edge e ON r.b=e.a
)
SELECT * FROM Reach;
\end{lstlisting}
\ex{Edges $\{(A,B),(B,C),(C,D)\}$: anchor gives AB,BC,CD; next rounds add AC,BD, then AD; fixed point $\{AB,BC,CD,AC,BD,AD\}$.}
\trap{UNION DISTINCT removes repeated reachability pairs and stops when no new pair exists. Adding path/depth to the tuple can keep producing distinct rows on cycles; deduplication alone then does not ensure termination.}
\end{topicblock}

\begin{topicblock}
\topic{07}{CONDITIONAL AGGREGATION}
% Source: Project 1 Q5; thresholds are explicit example inputs.
\when{Classify rows or aggregate only rows satisfying a condition.}
\pattern{Classify, then group}
Sales(price): non-NULL numeric prices.
\begin{lstlisting}
SELECT CASE
 WHEN price<10000 THEN 'Budget'
 WHEN price<40000 THEN 'Common'
 WHEN price<60000 THEN 'Luxury'
 ELSE 'Super' END AS car_category,
 COUNT(*) AS number_of_sales
FROM Sales
GROUP BY car_category ORDER BY car_category;
\end{lstlisting}
\trap{CASE uses the first matching branch; without ELSE, unmatched rows give NULL. Boundaries: 9999=Budget, 10000=Common, 40000=Luxury, 60000=Super. For nullable prices add an explicit NULL branch.}
\pattern{Conditional count / sum / mean}
Crime(location,type,amount); amount is numeric/NULL. P is a Boolean row predicate, e.g. \sql{type='THEFT'}; substitute it in the template.
\begin{lstlisting}
SELECT location,
 SUM(CASE WHEN type='THEFT' THEN 1 ELSE 0 END) AS theft,
 COUNT(CASE WHEN type='BATTERY' THEN 1 END) AS battery,
 SUM(CASE WHEN P THEN amount ELSE 0 END) AS total_p,
 AVG(CASE WHEN P THEN amount END) AS mean_p,
 MIN(CASE WHEN P THEN amount END) AS min_p,
 MAX(CASE WHEN P THEN amount END) AS max_p
FROM Crime GROUP BY location;
\end{lstlisting}
\trap{AVG/MIN/MAX should omit ELSE 0 when nonmatches must be ignored. COUNT(CASE ... ELSE 0 END) counts nonmatches too. SUM of no non-NULL inputs can still be NULL; COALESCE if zero is required.}
\ex{Two rows (P,amount)=(true,100),(false,50): AVG(CASE WHEN P THEN amount END)=100; adding ELSE 0 gives (100+0)/2=50. Conditional COUNT without ELSE=1; with ELSE 0=2.}
\key{Conflict detection}
\begin{lstlisting}
SELECT VIN FROM Cars GROUP BY VIN
HAVING COUNT(DISTINCT make)>1
    OR COUNT(DISTINCT model)>1;
\end{lstlisting}
For make values: Ford/Toyota is conflict; Ford/NULL, NULL/NULL, Ford/Ford are not (NULL is unknown, not a second known value).
\key{Grouping sets}
CUBE on d dimensions has $2^d$ grouping sets; ROLLUP(a,b,c) gives (a,b,c),(a,b),(a),(). MySQL supports \sql{GROUP BY a,b WITH ROLLUP}, not native CUBE. \sql{GROUPING(a)=1} identifies a generated subtotal NULL, distinct from stored NULL.
\end{topicblock}

\begin{topicblock}
\topic{08}{RANKING / TOP K}
\when{Highest, second distinct, or top K values within each group.}
\pattern{Rank, then filter} Employee(id PK,dept,score); score numeric/NULL, K a positive integer.
\begin{lstlisting}
WITH Ranked AS (
 SELECT e.*, DENSE_RANK() OVER (
  PARTITION BY dept ORDER BY score DESC
 ) AS r
 FROM Employee e WHERE score IS NOT NULL
)
SELECT * FROM Ranked WHERE r=2
ORDER BY dept, score DESC, id;
\end{lstlisting}
\sql{r=1}: all highest ties; \sql{r=2}: second distinct score; \sql{r<=K}: top K distinct score levels. ROW\_NUMBER<=K: at most K rows per group; add unique id as window tie-breaker for determinism.
\begin{center}\begin{tabular}{@{}lrrr@{}}
score DESC & ROW\_NUMBER & RANK & DENSE\_RANK\\
90 & 1 & 1 & 1\\90 & 2 & 1 & 1\\80 & 3 & 3 & 2\\70 & 4 & 4 & 3
\end{tabular}\end{center}
\trap{Do not add a unique id to the ranking order when ties must stay tied. Only final ORDER BY orders output; window ORDER BY controls calculation. RANK leaves gaps after ties.}
\pattern{Aggregate first, rank second}
Sales(state,make): one row per sale.
\begin{lstlisting}
WITH G AS (
 SELECT state,make,COUNT(*) AS n FROM Sales
 GROUP BY state,make
), Ranked AS (
 SELECT G.*,DENSE_RANK() OVER (
  PARTITION BY state ORDER BY n DESC) AS rk FROM G
)
SELECT state,make,n FROM Ranked WHERE rk=1;
\end{lstlisting}
\ex{CA counts Ford=2,Toyota=2,Honda=1: both Ford/Toyota rank 1. Rank grouped counts, not individual sales.}
Same-block shorthand inside a grouped SELECT:
\begin{lstlisting}
DENSE_RANK() OVER (
 PARTITION BY state ORDER BY COUNT(*) DESC)
\end{lstlisting}

\topic{09}{WINDOW FRAMES}

\topic{10}{ROUNDING / STORED PROGRAMS}

END//

\end{lstlisting}

\pattern{Filter on a calculated column}
Point(id PK,lat,lon): degrees, $-90\leq lat\leq90$, $-180\leq lon\leq180$. Set @lat0/@lon0 to valid target coordinates and @radius\_km $\geq0$. The CTE makes a calculated metric filterable/sortable.
\begin{lstlisting}
WITH D AS (
 SELECT p.*,2*6371*ASIN(SQRT(LEAST(1,
  POW(SIN(RADIANS(@lat0-lat)/2),2)
  +COS(RADIANS(@lat0))*COS(RADIANS(lat))
  *POW(SIN(RADIANS(@lon0-lon)/2),2)
 ))) AS distance
 FROM Point p WHERE lat IS NOT NULL AND lon IS NOT NULL
)
SELECT * FROM D WHERE distance<=@radius_km
ORDER BY distance,id;
\end{lstlisting}

\key{RULE: Haversine on a sphere}
Convert degrees to radians. For latitudes $\phi_1,\phi_2$ and longitude difference $\Delta\lambda$:
$a=\sin^2((\phi_1-\phi_2)/2)+\cos\phi_1\cos\phi_2\sin^2(\Delta\lambda/2)$;
$d=2(6371)\arcsin\sqrt{a}$ km; Earth radius is approximated by 6371 km.
\ex{Equator points (0,0) and (0,1 degree): $a=\sin^2(\pi/360)\approx0.0000761524$; $d\approx111.19492664$ km. Radius 112 includes it, radius 111 excludes it.}
% Source: Project 2 Q9; generalized from five safety bands to two categories.
\pattern{Trigger: Validate $\to$ Derive $\to$ Audit}
Score(id PK,score INT NULL,category); Audit(id,old\_v,new\_v). Allowed score: 1--99 or NULL; category is derived, never independently supplied.
\begin{lstlisting}
DELIMITER //
CREATE TRIGGER tr BEFORE UPDATE ON Score FOR EACH ROW
BEGIN
 IF NEW.score IS NOT NULL AND
    NEW.score NOT BETWEEN 1 AND 99 THEN
  SIGNAL SQLSTATE '45000'
   SET MESSAGE_TEXT='Invalid score';
 END IF;
 SET NEW.category = CASE
  WHEN NEW.score IS NULL THEN NULL
  WHEN NEW.score<50 THEN 'Low' ELSE 'High' END;
 IF NOT (OLD.score <=> NEW.score) THEN
  INSERT INTO Audit(id,old_v,new_v)
  VALUES(OLD.id,OLD.score,NEW.score);
 END IF;
END//
DELIMITER ;
\end{lstlisting}
\trap{Always derive; audit only score changes (NULL-safe). Category-only repair: no audit; NULL/value: audit; NULL/NULL: no audit. With transactional tables, audit rolls back with the caller.}

\begin{topicblock}
\topic{11}{RELATIONAL ALGEBRA}
\when{Translate queries using set semantics.}
R/S=relations; $P,\theta$=row/join predicates; A=attribute list; X/Y=disjoint attribute sets below.
Set semantics: relations contain distinct tuples. $\sigma_P(R)$ selects rows; $\pi_A(R)$ projects attributes and removes duplicates; $\rho$ renames; $\leftarrow$ assigns. $R\bowtie_\theta S=\sigma_\theta(R\times S)$; natural join matches every same-named attribute. $\cup,\cap,-$ require compatible arity/domains.
$|R\times S|=|R||S|$; $|\sigma_P(R)|\leq|R|$; $|\pi_A(R)|\leq|R|$; $|R\bowtie S|\leq|R||S|$.
\key{Division}
$R(X,Y)\div S(Y)$ returns X values paired with every Y in S:
$\pi_X(R)-\pi_X((\pi_X(R)\times S)-R)$.
\ex{R={(a,1),(a,2),(b,1)}, S={1,2}: result {a}. S empty gives $\pi_X(R)$; a SQL double-NOT-EXISTS over A can include A rows outside $\pi_X(R)$.}
\end{topicblock}

\begin{topicblock}
\topic{14}{PART II: FD / CLOSURES}
R=set of attributes; F=set of FDs; X/Y/U/V are attribute subsets; juxtaposition denotes set union.
FD $X\to Y$ holds when tuples equal on X must equal on Y. Trivial iff $Y\subseteq X$. $F^+$ = all FDs implied by F; $X_F^+$ = all attributes determined by X. $F\models X\to Y\iff Y\subseteq X_F^+$.
\key{Armstrong's axioms (sound + complete)}
Reflexivity: $Y\subseteq X\Rightarrow X\to Y$.
Augmentation: $X\to Y\Rightarrow XZ\to YZ$.
Transitivity: $X\to Y,\ Y\to Z\Rightarrow X\to Z$.
Derived: union $X\to Y, X\to Z\Rightarrow X\to YZ$;
decomposition $X\to YZ\Rightarrow X\to Y,X\to Z$;
pseudotransitivity $X\to Y,WY\to Z\Rightarrow WX\to Z$.
\key{RULE: closure algorithm}
1. Set result=X. 2. For each $U\to V\in F$, if $U\subseteq\mathrm{result}$, add V. 3. Repeat scans until no change. Test Y contained in result. Do not stop after only one scan.
\trap{An FD is a constraint on every legal instance. One current table satisfying it does not prove that it belongs to F; one counterexample disproves it for that instance. Superkey: $X^+=R$; candidate key: inclusion-minimal superkey.}
\end{topicblock}

\begin{topicblock}
\topic{15}{ALL CANDIDATE KEYS}
\key{Complete enumeration}
1. $M=R\setminus\bigcup_{X\to Y\in F}Y$: mandatory attributes (never on an RHS); every key contains M.
2. Enumerate $S\subseteq R\setminus M$ in increasing size; let $K=M\cup S$.
3. Skip K containing a known key. Compute $K_F^+$; if R, record K.
4. Check minimality: for every $a\in K$, $(K\setminus\{a\})_F^+\ne R$.
5. Continue through remaining subsets; one key does not prove completeness. Minimal means by inclusion, not minimum cardinality.
% Source: Assignment 1 A1; R0/F0 are the shared inputs for topics 15--17.
\ex{Shared inputs: $R_0=ABCDEF$; $F_0=\{A\to B,BC\to D,D\to A,C\to E,E\to F\}$.
M=C; $A^+=AB$, $B^+=B$, $C^+=CEF$, $D^+=ABD$.
$AC^+=ABCDEF$ via A to B, BC to D, C to E to F.
$BC^+=ABCDEF$ via BC to D to A, C to E to F.
$CD^+=ABCDEF$ via D to A to B, C to E to F.
Closures here use $F_0$. All keys: AC, BC, CD. C alone fails; CE/CF/CEF add no A/B/D. Supersets of AC/BC/CD are nonminimal, proving completeness.}
\ex{Different key sizes: $F=\{A\to BC,BC\to A\}$ on ABC gives candidate keys $\{A,BC\}$. Both are inclusion-minimal; sizes 1 and 2 are valid.}
\end{topicblock}

\begin{topicblock}
\topic{16}{BCNF / PROJECTED FDs}
BCNF: for every nontrivial FD $X\to Y$ in the fragment's projected dependencies, X is a superkey of that fragment. 3NF: X superkey OR each RHS attribute prime (in some candidate key). Standard 3NF synthesis preserves dependencies and ensures losslessness when a key-containing relation is included. 4NF: each nontrivial multivalued dependency $X\twoheadrightarrow Y$ has a superkey X. Normalization limits update/insert/delete anomalies from repeated facts.
\key{RULE: recursive BCNF decomposition}
1. Start with R. 2. In fragment $R_i$, find nontrivial projected $X\to Y$ with $X^+_{F_i}\ne R_i$.
3. Replace by $R_1=X\cup Y$ and $R_2=R_i\setminus(Y\setminus X)$; alternatively take $R_1=X^+_{F_i}$ and $R_2=X\cup(R_i\setminus X^+_{F_i})$.
4. Recompute projected dependencies and repeat on both fragments until BCNF. Different valid violation choices can yield different answers.
\ex{BCNF decomposition on $R_0,F_0$ from 15:
$ABCDEF\xrightarrow{E\to F}EF+ABCDE$;
$ABCDE\xrightarrow{C\to E}CE+ABCD$;
$ABCD\xrightarrow{A\to B}AB+ACD$;
$ACD\xrightarrow{D\to A}AD+CD$.
Result $D_{\rm BCNF}=\{AB,AD,CD,CE,EF\}$. Keys: A for AB, D for AD, C for CE, E for EF; CD has no nontrivial projected FDs.}
\key{Projection includes implied FDs}
$F_i=\{X\to Y\in F^+:X\cup Y\subseteq R_i\}$.
To compute a finite basis, for each $X\subseteq R_i$, compute $X_F^+\cap R_i$ and add nontrivial implied FDs; remove redundant ones. For ACD under $F_0$, a basis is $D\to A, AC\to D$; the second follows via $A\to B$ then $BC\to D$. This basis is not the entire projection.
\trap{Check projected FDs, including implied ones. Standard BCNF splitting is lossless but may lose dependency preservation. Two-attribute schemas are automatically BCNF only when nontrivial empty-LHS FDs are excluded.}
\end{topicblock}

\begin{topicblock}
\topic{17}{LOSSLESS / PRESERVATION}
\key{Binary lossless test (iff, under FDs)}
For $R=R_1\cup R_2$, lossless iff
$(R_1\cap R_2)\to R_1$ OR $(R_1\cap R_2)\to R_2$ is in $F^+$.
Repeated lossless binary splits compose. Covering all attributes alone is insufficient; lossy joins may introduce spurious tuples.
\key{Dependency preservation (DP)}
Let $G=\bigcup_i F_i$. DP iff $G^+=F^+$. It suffices to test every original $X\to Y\in F$ by $Y\subseteq X_G^+$.
Without enumerating projections: initialize result=X; for each fragment add
$t=((\mathrm{result}\cap R_i)^+_F)\cap R_i$ to result; repeat all fragments to a fixed point. If Y is still missing, FD is not preserved.
% Source: Assignment 1 A2; this GIVEN decomposition differs from D_BCNF above.
\ex{On $R_0,F_0$, test the given $D_{\rm test}=\{AB,ACD,CE,EF\}$. Its projected basis G includes $A\to B,D\to A,AC\to D,C\to E,E\to F$.
$(BC)^+_G=BCEF$: D never appears, so $BC\to D$ is not preserved. Iterative propagation: BC to BCE (CE), to BCEF (EF); AB and ACD add nothing further.}
\key{Multiway lossless: chase (FDs)}
1. Row per fragment, column per attribute j. Cell=$a_j$ if present; else fresh $b_{ij}$.
2. For rows agreeing on an FD's LHS, unify RHS symbols; replace all occurrences of unified symbols globally, preferring $a_j$ over b.
3. Repeat to fixed point. An all-a row iff lossless; no such row at termination means lossy.
\ex{R=ABC, fragments AB/AC, F={$A\to B$}. Rows initially $(a_A,a_B,b_{1C})$, $(a_A,b_{2B},a_C)$. Agree on A: unify $b_{2B}=a_B$. Second row becomes $(a_A,a_B,a_C)$: lossless.}
\key{MCQ: separate the guarantees}
\par\begin{tabular}{@{}lr@{}}
\textbf{Claim} & \textbf{True?}\\
Attribute cover $\Rightarrow$ lossless & No\\
BCNF fragments $\Rightarrow$ lossless & No\\
Standard BCNF algorithm $\Rightarrow$ lossless & Yes\\
BCNF algorithm $\Rightarrow$ DP & No\\
3NF synthesis + key $\Rightarrow$ lossless + DP & Yes\\
Each original FD fits a fragment $\Rightarrow$ DP & Yes\\
One original FD does not fit $\Rightarrow$ not DP & No
\end{tabular}\par
The last shortcut can fail even when DP holds: $F=\{A\to B,B\to C,A\to C\}$, fragments AB/BC; $A\to C$ is enforced through the other two FDs.
\ex{Lossy even with BCNF fragments: let $F=\{A\to B\}$ and $r=\{(a_1,b,c_1),(a_2,b,c_2)\}$. This r satisfies F. AB and BC are BCNF, but $\pi_{AB}(r)\bowtie\pi_{BC}(r)$ also produces $(a_1,b,c_2),(a_2,b,c_1)$: four rows instead of two. Always build a counterexample satisfying the given FDs.}
\end{topicblock}

\begin{topicblock}
\topic{19}{XPATH / PREDICATES}
\when{Navigate a tree; filter nodes by context or position.}
\sql{/}: document node; \sql{/r}: root element r. \sql{x} or \sql{./x}: child x; \sql{//x}: from document root, descendant x; \sql{.//x}: descendant x of current context; \sql{..}: parent; \sql{@id}: attribute. \sql{*} element children, \sql{@*} all attributes; \sql{text()} text children; \sql{node()} any child node. \sql{string(x)} string value; \sql{count(x)} number of selected nodes.
\ex{Tree: \sql{<r><g><x id="1"/></g><x id="2"/></r>}. Context g: .//x selects id1; //x selects id1,id2; ../x and /r/x select id2. \sql{@id/text()} is empty (attributes have no text children); \sql{string(@id)} returns the value.}
\key{Positions (P = XPath predicate)}
\sql{x[1]} first child x; \sql{x[last()]} last; \sql{x[position()=2]} second. Positions start at 1 (Mongo array indexes start at 0).
\sql{[credits]} tests child existence, not positive credits. \sql{[credits>0]} tests a value. \sql{x[P][1]} filters then first; \sql{x[1][P]} first then filters. \sql{(//x)[1]} first globally; \sql{//x[1]} first x child for each parent.
\ex{Credits [0,3]: course[credits] includes the 0-credit course; course[credits>0][1] gives the second course, but course[1][credits>0] gives nothing. For a default-namespace document bind a prefix in XPath/XQuery and use it (e.g. u:course).}
\key{ID lookup / union / axes}

\begin{topicblock}
\topic{20}{XQUERY / COMPARISONS}
\when{Filter/join XML, group values or construct output trees.}
\ruleline{FLWOR: for binds each item; let binds a sequence; where filters; order by sorts; return emits values/nodes. In direct constructors braces evaluate expressions; outside braces \sql{$x} is literal text.}
\begin{lstlisting}[style=Plaincode]
for $x in (2,4) return count($x)  (: (1,1) :)
let $x := (2,4) return count($x)  (: 2 :)
\end{lstlisting}
General \sql{= != < > <= >=}: existential pairs after atomization. Value \sql{eq ne lt gt le ge}: each atomized operand has at most one item; empty gives empty, multiple items errors. \sql{is}: node identity, not text equality.
\ex{(10,1)=10 is true, (10,1)!=10 is also true, but not((10,1)=10) is false. General != is not the negation of general =. (10,1) eq 10 is an error.}
\sql{some $x in S satisfies P}: any true; \sql{every $x in S satisfies P}: all true. S=sequence; P=Boolean expression in x. Empty S: some=false, every=true, count=0, exists=false, empty=true.

for $m in doc("museums.xml")/Museums/Museum

 ($a/Artist eq $b/Artist and $a/Title ne $b/Title)

One outer iteration per museum: multiple qualifying pairs do not duplicate its MName.
% Source: Assignment 1 B3; preserve parents with empty child groups.

  $m/Artworks/Artwork)}</TotalArtworks>

let $u := doc("university.xml")/university

\topic{21}{MONGODB: CRUD / FILTERS}
\when{Read/write documents, filter fields or update arrays.}
BSON is binary serialization with ObjectId, Date, int32/int64, Decimal128 and binary types; JSON is text. Collections hold documents with a unique \sql{_id}. Flexible schema still has data types and may enforce validation.

\pattern{CRUD on the independent collection c}
\begin{lstlisting}[style=Plaincode]
db.c.insertOne({a:1}); db.c.insertMany([{a:2},{a:3}]);
db.c.find({a:{$gte:2}},{_id:0,a:1}).sort({a:-1}).limit(5);
db.c.updateOne({a:1},{$set:{a:4},$inc:{n:1}});
db.c.updateMany({old:true},{$unset:{old:""}});

\end{lstlisting}
\key{Replacement / upsert / array updates}
\begin{lstlisting}[style=Plaincode]
db.c.replaceOne({name:"Alice"},
 {name:"Alice",age:30},{upsert:true});
db.sales.updateOne({"items.quantity":15},
 {$set:{"items.$.quantity":55}});
db.sales.updateMany({},{$set:{"items.$[i].flag":true}},
 {arrayFilters:[{"i.quantity":{$gte:3}}]});
\end{lstlisting}
updateOne modifies matching fields through update operators; replaceOne replaces the document except immutable \sql{_id} (retained if omitted). upsert:true inserts if no document matches. Replacement documents do not use \sql{$set/$inc}.
\par\begin{tabular}{@{}ll@{}}
\sql{$} & first query-matching array element\\
\sql{$[]} & all array elements\\
\sql{$[i]} & elements passing arrayFilters\\
\sql{$push} & append element\\
\sql{$addToSet} & append if absent\\
\sql{$pull} & remove matching elements
\end{tabular}\par
Comparison: \sql{$eq $ne $gt $gte $lt $lte $in $nin}. Logical: \sql{$and $or $not $nor}; field conditions implicitly AND. Existence/type: \sql{$exists $type}; arrays: \sql{$all $size $elemMatch}. \sql{$set} assigns, \sql{$unset} removes a field, \sql{$inc} adds a number. \sql{$not} wraps a field condition; \sql{$or/$and/$nor} take condition arrays.

Inclusion: fields with 1; exclusion: 0. Cannot mix inclusion/exclusion except \sql{_id:0}; \sql{_id} included by default. sort 1 ascending, -1 descending; multiple fields are tie-breakers in specified order.

\begin{topicblock}
\topic{22}{MONGODB: AGGREGATION}
\when{Group documents, compute metrics or reshape pipeline output.}
\pattern{Document filter, aggregate filter, rounded sort}
\begin{lstlisting}[style=Plaincode]
db.trips.aggregate([
 {$match:{birthYear:{$gte:1980},duration:{$gte:300}}},
 {$group:{_id:"$stationId",tripCount:{$sum:1},
          avgDuration:{$avg:"$duration"}}},
 {$match:{tripCount:{$gte:2}}},
 {$project:{_id:0,stationId:"$_id",tripCount:1,
            avgDuration:{$round:["$avgDuration",1]}}},
 {$sort:{avgDuration:-1,stationId:1}}
]);
\end{lstlisting}
SQL mapping: FROM=collection, WHERE=\sql{$match} before \sql{$group}, GROUP BY=\sql{$group}, HAVING=\sql{$match} after \sql{$group}, SELECT=\sql{$project}, ORDER BY=\sql{$sort}, LIMIT=\sql{$limit}.
\sql{$sum:1} counts input documents; \sql{$sum:"$x"} sums x; \sql{$avg:"$x"} averages numeric x; \sql{_id:null} makes one global group. \sql{"$field"} references a field; \sql{"field"} is a string literal. \sql{$group} does not promise output order.
% Sources: A2.Q1.2 and P2.Q7; separate the reusable stage-order decisions.
\key{RULE: stage-order guide (schematic)}
\sql{$project(round) -> $sort}: sort rounded values.
\sql{$sort -> $project(round)}: sort original values.
\sql{$match -> $group}: filter documents.
\sql{$group -> $match}: filter aggregate groups.
\trap{After \sql{$group}, fields not grouped/accumulated no longer exist. "round" above stands for the explicit rounding expression in a projection.}
\ex{Input trips (stationId,duration,birthYear): (1,300,1990), (1,600,1990), (2,900,1990). All pass the first match. Group 1: count2, mean450; group 2: count1, mean900. Output: stationId1, tripCount2, avgDuration450.0; group 2 fails the aggregate threshold.}
\key{Pipeline-stage fragments (inside aggregate)}
\sql{$addFields} computes/preserves fields; \sql{$project} selects/computes; \sql{$unwind} emits one document per array element; \sql{$sort} then \sql{$limit} obtains top results.
\begin{lstlisting}[style=Plaincode]
{$unwind:{path:"$items",preserveNullAndEmptyArrays:true}}
{$group:{_id:"$items.name",n:{$sum:1},
         revenue:{$sum:{$multiply:["$items.quantity",
                                  "$items.price"]}}}}
\end{lstlisting}
\trap{Default \sql{$unwind} drops empty/null/missing arrays; preserveNullAndEmptyArrays retains them. After unwind, sum:1 counts emitted items/rows, not original sales; count distinct sale IDs if sales are required.}
\key{Write/count stages (stage fragments)}
\begin{lstlisting}[style=Plaincode]
{$count:"total"}
{$out:"result"}
{$merge:{into:"result",on:"_id",
 whenMatched:"merge",whenNotMatched:"insert"}}
\end{lstlisting}
\sql{$count} counts pipeline documents (empty input gives no result document); \sql{$out} writes/replaces the target collection; \sql{$merge} incorporates results into the target. Pipeline \sql{$set} adds/modifies fields (alias of \sql{$addFields}).
\trap{\sql{$out} or \sql{$merge} must be the last stage; choose the required output action. Ordinary aggregation transforms its result without changing source documents unless a write-output stage is used.}
\key{Single-purpose aggregation}
\begin{lstlisting}[style=Plaincode]
db.c.countDocuments({score:{$gte:50}});
db.c.distinct("department",{active:true});
db.c.estimatedDocumentCount();
\end{lstlisting}
countDocuments(filter) counts matches; distinct returns unique field values; estimatedDocumentCount uses metadata to estimate the total collection count.
\end{topicblock}

\topic{24}{ARRAY PROJECTION PATTERNS}
\when{Choose first matching, original first or all qualifying items.}
\pattern{First qualifying array element}
\begin{lstlisting}[style=Plaincode]
db.sales.find(
 {items:{$elemMatch:{quantity:{$gte:3},price:{$gte:80}}}},
 {_id:0,saleId:1,"items.$":1}
).sort({saleId:1});
\end{lstlisting}

\begin{lstlisting}[style=Plaincode]
db.sales.find({}, {_id:0,saleId:1,
 items:{$elemMatch:{quantity:{$gte:3},price:{$gte:80}}}});
\end{lstlisting}

\pattern{Original first item qualifies}
\begin{lstlisting}[style=Plaincode]
db.sales.find(
 {"items.0.quantity":{$gte:3},"items.0.price":{$gte:80}},
 {_id:0,saleId:1,"items.name":1,
  "items.quantity":1,"items.price":1}
).sort({saleId:1});
\end{lstlisting}
\trap{The filter checks original index 0; dotted projection returns fields for ALL items. Input 23 selects C and keeps c0,c1. Slicing is positional, not conditional.}
\begin{lstlisting}[style=Plaincode]
{items:{$slice:2}}      // first 2
{items:{$slice:-2}}     // last 2
{items:{$slice:[3,2]}}  // skip 3, take 2
\end{lstlisting}
\pattern{All qualifying elements: \$filter}
\begin{lstlisting}[style=Plaincode]
db.sales.aggregate([
 {$match:{items:{$elemMatch:{quantity:{$gte:3},
                           price:{$gte:80}}}}},
 {$project:{_id:0,saleId:1,items:{$filter:{
  input:"$items",as:"i",cond:{$and:[
   {$gte:["$$i.quantity",3]},{$gte:["$$i.price",80]}
  ]}}}}},
 {$sort:{saleId:1}}
]);
\end{lstlisting}

\begin{topicblock}
\topic{26}{SPARK / RDD}
\when{Trace distributed transformations/actions or count their outputs.}
sc=SparkContext; spark=SparkSession, both initialized by the caller.
RDD = distributed, partitioned, immutable collection. Transformations create new RDDs; lineage records dependencies for fault recovery. Lazy: an action triggers computation. cache()/persist() marks reuse; partitions are populated only when computed by an action.
\key{Transformations: return a new RDD}
\par
\begin{tabular}{@{}lll@{}}
\textbf{Operation} & \textbf{Effect} & \textbf{Size}\\
\sql{map} & one output/input & $n$\\
\sql{flatMap} & zero or more/input & $\sum_i k_i$\\
\sql{filter} & matching inputs & $\leq n$\\
\sql{distinct} & deduplicate & $\leq n$\\
\sql{union} & keep duplicates & $n+m$\\
\sql{groupByKey} & iterable/key & $|K|$\\
\sql{reduceByKey} & aggregate/key & $|K|$\\
\sql{sortByKey} & order keys & $n$
\end{tabular}\par
$n$=input count; $m$=other RDD count; $k_i$=flatMap outputs from input $i$; $K$=set of distinct keys. Group/reduce output ordering is unspecified unless sorted.
\key{Actions: compute, return or write}
\par
\begin{tabular}{@{}ll@{}}
\sql{collect} & all elements to driver\\
\sql{count} & number of elements\\
\sql{first()/take(k)} & first element / at most k\\
\sql{takeOrdered(k)} & smallest k by optional key\\
\sql{reduce} & one aggregate value\\
\sql{countByKey} & counts per key at driver\\
\sql{saveAsTextFile} & write output files
\end{tabular}\par
k=nonnegative integer limit. collect can exhaust driver memory. first/reduce error on empty input; take/takeOrdered return up to k elements. Distributed reduce needs an associative, commutative operation for order-independent results.
\pattern{take versus takeOrdered}
\begin{lstlisting}[style=Plaincode,language=Python]
r = sc.parallelize([5,1,3,2])
r.collect()                 # [5,1,3,2]
r.take(2)                   # [5,1]
r.takeOrdered(2)            # [1,2]
r.takeOrdered(2, key=lambda x:-x)  # [5,3]
r.count()                   # 4
r.reduce(lambda a,b:a+b)     # 11
\end{lstlisting}
\trap{take(k) reads the first k elements; it is not top-K by value. takeOrdered(k) selects the smallest by its key; a negative numeric key gives largest values first.}
\ex{RDD r holds [('a',1),('b',2),('a',3)]. map(lambda kv:kv[1]) gives [1,2,3]; filter(lambda kv:kv[1]>1) gives [('b',2),('a',3)]; groupByKey gives a:[1,3], b:[2] (iterables, order unspecified); reduceByKey(+) gives a:4,b:2. r.count()=3; reduced.count()=2.}
\pattern{Word count}
\begin{lstlisting}[style=Plaincode,language=Python]
counts = (sc.textFile('notes.txt')
    .flatMap(lambda line: line.split())
    .map(lambda word: (word, 1))
    .reduceByKey(lambda a, b: a + b))
out = counts.collect()
\end{lstlisting}
If notes.txt has lines ['a b','a']: flatMap gives a,b,a; map gives (a,1),(b,1),(a,1); reduceByKey gives a:2,b:1.
\key{RULE: dependencies / shuffle}
Narrow: each child partition depends on limited parent partitions (map/filter need no shuffle). Wide: redistributes data, typically by shuffle. reduceByKey combines locally before shuffle; groupByKey groups values. Prefer reduceByKey for associative/commutative aggregation. A compatible existing partitioner may avoid a new shuffle.
\key{MapReduce / DataFrame}
MapReduce: input $\to$ map $\to$ shuffle/group $\to$ reduce. DataFrame example: x.csv has a header with a name column.
\begin{lstlisting}[style=Plaincode,language=Python]
df = spark.read.option('header',True).csv('x.csv')
df.select('name').filter("name IS NOT NULL").show()
df.createOrReplaceTempView('T')
spark.sql('SELECT COUNT(*) FROM T').show()
\end{lstlisting}
